# release Handoff Supplement

New `release` communication-contract handoffs use presentation 9 and include a second table named `Readiness`, with `Check | Status | Evidence | Blocker / next action`. Its rows exactly match the `## Checks` table in `release-readiness.md`; each check has a distinct source record. The shared release artifact validator binds these rows. The current renderer moves every file path in any table cell, including Evidence and mixed blocker/action cells, into `- <item>: <file-path>` lines immediately below the table while preserving non-path prose and complete machine evidence. Historical one-table release handoffs retain their exact rendering.
